# Security policy

## Supported source

Security fixes target the current `main` branch. This repository is a draft documentation site and has no supported versioned package releases.

## Report a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/VINASIG/web-design-system/security/advisories/new) to share a suspected vulnerability with the repository maintainers. Include the affected commit, reproduction steps, expected impact and a minimal example that avoids credentials or personal data.

If the private form is unavailable, open a public issue asking maintainers to provide a private reporting channel without including vulnerability details. Do not post secrets, account tokens or exploit details in an ordinary issue.

The project does not set a guaranteed response deadline. This policy covers the source and documentation in this repository. Reports about an external service belong with that service's maintainer.
