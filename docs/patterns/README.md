# Patterns

**Status:** Draft proposal. Patterns describe reusable solutions to common page-level tasks.

## Forms

Group related fields, label each field, explain required formats before submission, and summarize what needs correction after an unsuccessful submit. Preserve valid entries when the user returns to fix an error.

## Empty states

Explain why the region is empty, what the user can do next, and provide one clear action when an action is available. Keep decorative copy secondary to the next step.

## Loading and errors

Use a loading indicator only when work takes long enough to interrupt the user's sense of progress. For errors, describe the issue in plain language and give a recovery action when possible.

## Page layout

Keep navigation stable across related pages. Establish one clear page title, group content by task, and let the page reflow naturally on mobile. Avoid requiring horizontal scrolling for ordinary content.
